# nowqtt add-ons

A Home Assistant add-on repository with one add-on: the **nowqtt console**, the
management interface for a nowqtt ESP-NOW mesh.

Add this repository in Home Assistant under
**Settings → Add-ons → Add-on store → ⋮ → Repositories**.

This repository is generated from the nowqtt gateway tree by
`addon/publish.sh`; edits made here are overwritten by the next publish.
